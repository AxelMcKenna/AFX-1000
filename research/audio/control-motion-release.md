# Scene control motion and Release return

This checkpoint addresses the four failures remaining after the [tempo work](tempo-transitions.md): Echo, HPF Echo and Crush Main/Sub 1 motion, and Back Spin combined with Reverb Up. The reference is RMX-1000 Plug-in 2.2.0, Default settings at 48 kHz. The declared performance suite and fresh timing holdouts are software evidence; they do not establish physical-device equivalence or a whole-device accuracy percentage.

The frozen final build passes **54/54 active regression programs and all 54 paired controls**, plus **18/18 fresh Scene/Release timing holdouts and their controls**. All six regression families pass 9/9. The [regression report](measurements/2026-11-03-motion-release-regression.json.gz), [holdouts](measurements/2026-11-03-motion-release-holdout.json.gz), [independent window audit](measurements/2026-11-03-motion-release-window-audit.json.gz) and [validation receipt](measurements/2026-11-03-motion-release-validation.json) retain the exact bindings and results. All 108 Original regression audio hashes repeat the initial fresh campaign; the later 18 switch and 18 tempo checkpoint hashes also repeat.

## What changed

**HPF feedback order.** Static filter transfer factors commute, but their changing internal states do not. During motion, feedback must pass through the Main biquad and then its complementary first-order section. The previous cold path updated a separately factored feedback filter. Its complete output looked close while its smaller active-minus-control signal failed. The corrected order applies after control motion starts; settled static arithmetic is preserved. LPF motion also improves.

**Echo control clocks.** Main and Sub 1 targets are taken from the shared 32-frame command block. Applying the generic exponential parameter smoother first delayed their effect and made Sub 1 cross delay divisions at the wrong time. Main's measured effect amount instead ramps linearly over 160 samples. Retiming tracks the actual selected delay, including Sub 1 changes, using the existing 160-sample fade-out/fade-in and block-cached read position. An earlier attempt to retime Sub 1 while retaining the generic smoother failed; the tempo archive keeps that rejected hypothesis.

**Crush hold and mix clocks.** The fractional sample-hold clock carries both an integer count and a float32 fractional remainder. It retains those states across Main changes. Starting the active clock at count one and preserving each float32 operation reproduces all 350 sampled reference count/fraction states in an independent NumPy replay. This scalar check is distinct from the full-waveform comparison.

The remaining Crush error was concentrated in the first 32-frame block of a Main gesture. Its dry blend ramps the underlying position over 32 samples, then squares that position; interpolating the squared gain gives different samples. The initial position must also be initialized before the first private active block. Without that initialization the first gesture ramps from the reset value, despite subsequent gestures behaving correctly. Failed clock/blend models and the dense block-energy diagnostic are retained in provenance.

**Release sampler reset.** Returning Release with sampler retention disabled already stopped voices and cleared the generic sequence. The factory command recorder also needs its stop/clear cue on the shared command clock inside that same callback. Deferring it until the next host callback allowed a recorded hit to replay after return. Reverb Up made the resulting excess audio visible in reference-silent windows. A public regression compares Release return with explicitly disabling recording before a long callback. It passes with the fix and fails when only the old reset behavior is restored.

## Evidence and reproduction

The [campaign runner](../../tools/audio/performance/rmx_performance_path.py) freezes source and executable hashes, checks complete optimized/ASAN/UBSAN WAV identity before each Original render, validates parameter/transport receipts and independently scores the captured samples. Each active program has a matched drum/source control. Both sides discard the fixed first 32 frames; no gain, alignment or crop is fitted. Complete output, one-second, event and active-minus-control windows must each meet the unchanged 1% relative RMS gate per channel; reference-silent channels use 1e-8 absolute RMS.

The [read-only observer](../../tools/audio/performance/rmx_performance_path_observe.py) supports `--mode performance-selector --family scene --effect-index 6` for Crush. Supply the pinned Intel host, Original bundle, a new output and `--expected-output-sha256` from the regression report. Ordinary and observed audio, plans, state, parameter logs, inventory and transport hashes must agree. Only scalar controls are observed; no Original sample buffers are read and no DSP state is written. Original assembly is not retained.

Run `uv run --locked python -m tools.audio.performance.rmx_performance_path --stage fresh` with explicit renderer, sanitizer, host, plugin and new output paths for the complete regression. Use `--stage fresh2 --family scene --family release` for the fresh timing holdouts. The [energy auditor](../../tools/audio/performance/rmx_performance_path_audit.py) can recompute retained window verdicts after automatic audio deletion. The provenance archive includes the independent clock replay and temporary experiment scripts.

Captures run serially within a 512 MiB temporary-file budget. Compact scores, hashes, plans and source snapshots are retained; raw audio and redundant builds are removed. The pause marker and canonical reference installation remain untouched. Wider profiles, rates, activation sequences, transport gestures, arbitrary combinations, musical material and hardware remain separate qualification work.

The [provenance archive](measurements/2026-11-03-motion-release-provenance.json.gz) retains failed hypotheses and the earlier passing Crush partial whose final guard was invalidated by a concurrent sanitizer rebuild. That partial does not qualify production. The final complete regression and holdout campaigns began after all probe builds finished and passed the source/binary guards.

Of those 304 comparisons, 297 preserve complete output/dry WAV bytes. Seven active outputs intentionally change: Scene Echo/HPF/LPF/Crush, Release Back Spin/Reverb Up, and Crush switching/routing. Each changed performance output is tied to its passing new Original regression. Input-only preservation creates no additional Original qualification.
