# Release effect matching

29 October 2026. Back Spin, Echo and Vinyl Brake now run through the live Engine at 48 kHz with the Default profile. The measured scope is 120 BPM, input audio selected for FX, other effects off, and the original **RMX-1000 Plug-in 2.2.0**. This is software-reference matching; physical hardware and a whole-device 99% claim remain unqualified.

The [complete sample-identity check](measurements/2026-10-29-release-complete-sample-identity.json) verifies that all **216 programs** pass the unchanged 1% per-channel waveform gate. More strongly, every float32 sample bit in their complete native renders equals its original-reference sample, including startup, lever edges and return to dry. WAV container bytes differ between writers. The programs comprise 40 discovery recordings, 88 former fresh recordings used for development, and **88 genuinely unseen programs predicted before capture**. Do not count the former fresh set as prospective evidence after it informed corrections.

## How the behavior was identified

The [initial comparison](measurements/2026-10-29-release-initial-comparison-failed.json) passed only four neutral baselines and failed all 36 active programs. Each type was tested at raw lever 85, 170 and 255 against stereo tones, sparse impulses, chirps and deterministic broadband input. All runs used fixed 32-frame reference and candidate offsets, with no gain fitting or alignment search. Whole-output, active, return and 2,048-frame edge windows were retained throughout development.

The discovery recordings exposed timing and playback differences that a generic reverse, echo or speed ramp did not reproduce. Sparse read-only observations of the locally installed original identified the control states, speed accumulators, filter coefficients and ramp values. [`release_observer.py`](experiments/release_observer.py) pins the original DSP binary SHA-256, stops at selected internal blocks and records a bounded collection of numerical scalars. It writes no original instructions or sample buffers. Completed observed runs were checked against ordinary runs: their full audio and five auxiliary artifacts were byte-identical. One incomplete Back Spin debugger run was discarded and repeated serially; it supplies no sound evidence.

The observations establish the following functional model:

- The public lever truncates normalized travel into four positions: `85 * trunc(float32(value) * 3)`. A separate [257-request sweep](measurements/2026-10-29-release-lever-quantization.json) checks every requested 8-bit value and a final return to zero. Sparse DSP observations confirm that this affects the audio processor, as well as the displayed readback.
- Returning the GUI lever to zero holds internal lever 1 for five 32-sample blocks before the wet/dry return begins. This edge must be latched when controls arrive: an entire short touch can occur between two generated audio blocks.
- Changing the selected Release type while active first fades the current output down over 160 samples, initializes the new type, and fades it up. Cold activation therefore needs the same transition from the initial unselected state. Selecting a type with the lever off initializes it directly.
- Float operation order matters. The new processing translation unit disables multiply-add contraction; the float speed, gain, interpolation and first-order filter updates retain their observed rounding.

The numerical equations are implemented independently in the three `CalibratedRelease*.h` components. Their models consume generated input and controls; no reference recording is read by the renderer or embedded in the application.

## Playback and feedback

**Vinyl Brake** records from the touch and plays that recording forward at a decreasing float32 speed. Default regions use 16, 4 and 0.75 beats. Below speed 0.125 the decrement changes to a fixed small value, producing a longer final tail than a straight ramp. Two first-order filters, bounded filter state, linear sample interpolation and a piecewise speed-to-level curve reproduce the changing sound. A previous routing test assumed a short custom brake time in Default mode; it now explicitly selects User mode when testing that custom control.

**Back Spin** continuously records raw history, freezes a reachable reverse window at activation, and accelerates toward speed 8 before decelerating. Its reverse reader holds samples and carries fractional advancement between samples. The stereo reader's one-sample left/right offset, the separate grain fade, speed-dependent level curve and two first-order filters are audible parts of the model. The snapshot is copied ahead of the reader in bounded 320-frame increments per generated block; activation does not perform a large history copy.

**Echo** captures the initial period and recirculates it at feedback 0.7, with independent capture gates, input readiness, wet/dry ramps and a retiming fade. The output uses the current captured-plus-feedback signal. It is not simply a delayed tap mixed with dry input. Returning the lever retimes the default shorter divisions toward the first division. A short touch continues feeding the capture during its return ramp; prematurely dropping that feed caused three retained failures. Feedback resets when the dry return completes, rather than immediately on lever release. The ring writer continues through inactive periods.

## What the fresh checks changed

The first 88-program prediction included different tones, chirps, noise seeds, impulse times and callback sizes, plus boundary requests, moving controls, retriggers, cold activation and touches shorter than an internal block. Strict reference validation rejected the first boundary case because it assumed identical requested and returned lever values. The [validation failure](measurements/2026-10-29-release-fresh1-control-validation-failed.json) remains recorded; no active program was credited from that rejected comparison.

After the separate lever sweep established the mapping, those 88 recordings became development evidence. The corrected control mapping initially passed 64/88 programs. Modeling the master type-transition fade and latching short control edges raised this to 85/88. Retaining Echo's capture feed through the return closed the final three short-touch failures. These intermediate sources, binaries and failed comparisons remain in ignored local checkpoints.

The [second 88-program prediction](measurements/2026-10-29-release-fresh2-predictions.json) then changed the audio, random seeds, impulse positions and lever-event timing again. Its predictions bind the full source map, renderer binary, exact input WAVs, recipes, output hashes and acceptance gates before the original captures are made. Every output matches its frozen prediction. Each capture receipt is later than the prediction timestamp. All 88 [pass without changing the frozen model](measurements/2026-10-29-release-fresh2-holdout.json), with a separate [independent audit](measurements/2026-10-29-release-fresh2-audit.json).

## Integration and verification

[`FactoryRelease.cpp`](../../src/core/FactoryRelease.cpp) processes one common-clock block after Scene processing. The existing transport FIFO provides the measured 32-frame latency, including partial host callbacks. Raw history continues on that clock while a Release processor is selected. The original 40 programs, former 88 and unseen 88 supply **1,848 stereo waveform screens** across whole and declared interval windows.

[`rmx_release_audit.py`](../../tools/rmx_release_audit.py) independently recomputes the numerical scores, verifies complete recipe/window coverage and checks original inputs, binary hashes, receipts, plans, immediate/final readbacks and all auxiliary artifacts. It requires the actual Engine and Release symbols and instrumented processing translation units. Every complete optimized render must equal its AddressSanitizer/UndefinedBehaviorSanitizer render byte for byte. Passed and failed windows are never removed or fitted away.

The legacy and measured Release implementations share prepare-time backing storage because they run mutually exclusively. Changing between Default and User settings invalidates the other interpretation's history without allocating or clearing a large buffer in the audio callback. Unwritten history reads as zero. The measured processors share one work region and a separate continuously recorded raw region. This adds approximately 148 kB to the previous single-engine arena footprint, rather than keeping another six-megabyte set of buffers live.

Native tests exercise all three types, short and oversized callbacks, repeated reset, Default/User storage transitions and zero callback allocations. Both the ordinary memory check and a complete 64-second SD-card bank replacement stay within the existing 60 MiB arena. The app, AU and VST3 are rebuilt from the live Engine. The [AU](measurements/2026-10-29-release-au.json) and [VST3](measurements/2026-10-29-release-vst3.json) each pass all 88 programs; the largest native-delivery absolute sample difference is 2.5331974e-7. Wrapper waveform checks replay the existing 88 unseen originals through normalized parameters with the same waveform gates, plus separate `1e-5` native-delivery limits and reported latency 32. These are regressions using the same originals, not another 176 fresh recordings. Both formats also pass all 359 runtime smoke checks.

Compatibility checks preserve all [836 prior dry/moving/combined drum programs](measurements/2026-10-29-release-prior-drums-compatibility.json), [89 drum-roll programs](measurements/2026-10-29-release-prior-roll-compatibility.json) and [1,513 reverb programs](measurements/2026-10-29-release-prior-reverb-compatibility.json). Every complete prior audio/dry trace is unchanged; optimized and instrumented drum/roll renders agree byte for byte. The inherited near-null mixed Crush wet-window failure remains failed. The [final validation record](measurements/2026-10-29-release-final-validation.json) binds tests, reports, build settings and archived artifacts.

## Reproduction and limits

Use `uv run --locked python -m tools.rmx_release --help` for `predict`, `capture` and `compare`. Select `discovery`, `fresh` or `fresh-v2`; non-discovery capture requires the frozen prediction and renderer. Destinations must be new. `--regression` labels a comparison as development and cannot supply new prospective qualification. Use `tools.rmx_release_audit` for the independent audit and `tools.rmx_release_plugins` for explicit AU/VST3 delivery checks.

Original recordings, installers, binaries, private instruction inspection and local scalar traces remain ignored artifacts. Committed evidence contains numerical results, source/binary/artifact hashes and the independently written implementation.

The current campaign does not qualify other sample rates or tempos, User settings, active type switching beyond the tested cold transition, combined Scene/Isolator/drum reset actions, source-routing combinations, Hold/Quantize, DAW automation or physical controllers. Other rates and User profiles retain the prior approximation. Exact agreement in this measured Default/48k/120 BPM scope does not establish 99% agreement across the entire device.
