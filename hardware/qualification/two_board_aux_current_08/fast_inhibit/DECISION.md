# Decision: retain comparator family; implement a 3.3 V AUX architecture

Select **3.3 V AUX with TPS3703A5330DSER inhibit**, the eight resistor corrections in `functional.json`, and an **independent TPS62175DQCR 5 V preregulator feeding P_U102**. This is the chosen implementation direction; the 2.6 V comparator-swap alternative is closed. Physical implementation and qualification gates remain separate: no schematic or PCB was changed by this record.

| Criterion | Selected 3.3 V architecture | Rejected 2.6 V / TLV170x substitution |
|---|---|---|
| Existing comparator footprint/pin function | All five TLV182x retained | Quad TLV1704 is TSSOP-only; dual TLV1702 is VSSOP/QFN. Three installed SOIC quads and one SOIC dual require footprint changes. TSSOP pin functions match the standard quad arrangement, but this is not five drop-in replacements. |
| Analog transfer | Existing comparator error assumptions remain; four reference-window resistor values corrected | Full-temperature offset ±5.5 mV and bias20 nA replace prior ±4 mV/1.2 nA assumptions across18 channels. No guaranteed internal-hysteresis bound located; switching table is typical-only. |
| Logic low | Existing TLV182x interfaces retained | TLV170x output-low maxima are specified at36 V (up to900 mV); actual2.6 V low level is not bounded by that table. The existing AUP3G17 negative threshold minimum is690 mV at2.3 V, so the published bound does not prove a low. |
| Package current | Existing81-package ledger retained plus new supervisor |100 µA/channel maximum across18 channels versus existing TLV182x table subtotal; roughly1.66 mA increase before state qualification. |
| Detection/reservoir |30 µs full-range supervisor maximum;5.77 µF effective requirement under100 mA/20 mV/1 µs allocations |Direct2.5 V/3% window supervisor would consume nearly all margin above2.25 V after5% overdrive, requiring about0.18 mF effective for the same allocated load/delay. A shifted divider reduces this but adds input-current/ratio uncertainty and a narrow release window. |
| Regulator heating |Independent5 V preregulator cuts LDO loss to~0.198 W at allocated100 mA |Comparator substitution alone leaves the existing high-drop LDO thermal problem. |

TLV170x facts are from the [manufacturer datasheet](https://www.ti.com/lit/ds/symlink/tlv1704.pdf), sections6–7.7. Do not transfer its current, offset or timing values to another comparator family. MCP6549 was also checked only to exclude a mistaken drop-in assumption: its quad op-amp-style supply/output pin arrangement differs from the installed LM339-style quad. No broader part search is required for this decision.

## Preregulator implementation contract

Use the [TPS62175 adjustable version](https://www.ti.com/lit/ds/symlink/tps62175.pdf) with10 µH /22 µF nominal output filter, local2.2 µF input capacitor, and105 kΩ/20 kΩ feedback divider. It operates from4.75–28 V; the existing protected-input scenario is9.8–13.2 V. Its power-save accuracy is−1.8/+3% for this LC configuration. The selected nominal output is5 V. Divider total error±0.35% is a receiving allocation, and FB current100 nA is included. The resulting conditional range is4.870693–5.190925 V. `preregulator.json` contains exact pin connections and component requirements. Do not replace its primary specification with a typical efficiency curve.

Connect VIN and EN directly to VIN_IC, independent of POWER_READY. Connect P_U102 IN8 and EN5 to the new preregulator output, retaining its local input bypass. Existing NF_RAW5 cannot be used as the AUX source: it comes from F_U401 fed by5V_DIG_SRC, whose P_U20 buck enable is AUX-derived. Reusing it introduces a startup dependency cycle. Keep the new buck PG unused unless a separately checked sequencing design requires it. Keep the switched loop away from comparator/reference/Kelvin nodes, with short VIN-cap/PGND and SW/L/output-cap loops.

At the allocated100 mA output and100 µA LDO ground current, maximum LDO dissipation becomes0.197654 W. The existing66.2°C/W comparison board would produce98.1°C junction at85°C ambient; actual installed thermal resistance must still be verified. The buck requires roughly0.52 W delivered power. Using its61.6°C/W comparison board and125°C junction ceiling gives a receiving efficiency requirement above44.5% at85°C; this is **not** a manufacturer minimum-efficiency claim. Layout, switching/core losses and enclosure measurements decide the actual margin.

Select exact passive MPNs against these requirements before creating the native footprint additions: effective output capacitance17.6–26.4 µF over bias/temperature/aging, local input capacitance≥1.76 µF, an inductor retaining the required L at temperature/current with peak capability at least1.2 A, input capacitor rating≥25 V and output capacitor rating≥10 V. These requirements reflect the existing normal-input scenario; transient stress coordination remains a system-level check. The family application's low-profile example inductor is not automatically accepted at worst fault current. The separate LMR36506 data sheet was examined for input-voltage headroom; it is not the selected controller or an additional open option.

## Remaining qualification before native implementation acceptance

Proceed with one design, checking: full input/RC/receiver contracts at3.3 V; new buck passive selection, startup and transient limits; actual AUX maximum current and derated thermal path; effective AUX hold-up capacitance and source/return drop; bounded loaded MOSFET discharge; startup no-false-enable and brownout waveforms. The3.3 V change already has concrete correction values and tests; the old comparator alternative must not distract from completing these checks. Native part placement/routing is owned by the parent integration task. This analysis does not release fabrication.
