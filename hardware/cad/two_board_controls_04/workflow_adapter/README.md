# Controls workflow adapter

`registry.json` is the merge input for the unified assembly. Import `controls.scad` with OpenSCAD `use` and call the registered zero-argument modules. Coordinates are housing world millimetres. Render only `role: installed` with `scene: true` by default; motion and receiving rows are independently selectable checks.

The adapter delegates to frozen sources without changing their geometry. It distinguishes physical lenses and panel hardware from maximum shafts, generic pot body allocations and wiring allowances. Installed purchased-part references are simplified geometry, not certified supplier solids. All 29 keycaps preserve the frozen shape; switch references omit terminals. The full 29-button rest-state mechanism delegates to `mechanism(b,0)` and includes holders, switch references, clips, spring rings and compliant pucks. Atomic switch and clip components have `scene: false`; the root holder component must also be excluded from the default scene to avoid duplication. No generic captured control boxes are added.

The registry binds 34 passive control board instances across 12 designs, in addition to the two main boards and separately owned sensor board. Its selected electrical project is `panel_electrical/assembly/panel.kicad_pro`; its complete assembly subtree is hash-bound, including 39 schematic pages. This does not release fabrication or prove current capacity or complete housing fit.

Run `python3 hardware/cad/two_board_controls_04/workflow_adapter/verify.py` from any directory. It checks recursive SCAD and schematic source closure, exact delegate tokens, installed/receiving separation, PCB quantities and hashes. Seven deliberately corrupted registries must be rejected. `build_registry.py` regenerates the adapter and manifest only after the frozen source selection has been reviewed; changing a hash does not qualify a design change.

Self-review found that a top-level electrical glob omitted child sheets; fixed by binding the complete selected assembly subtree and checking recursive Sheetfile closure. Static verification passes with 30 components, 315 source files, 34 PCB instances and 12 designs. Native export is delegated to the root integrated runner: the initial repository-qualified image lookup was unavailable locally and its attempted fetch timed out. Root confirms the same pinned image ID exists and will use its established `--pull=never` runner. No native CAD result is claimed here.

Intentional contacts describe seating only and are not blanket interference exemptions. The final connected guide and lid remain separate components from the button indicators. Parent assembly checks must assess these contacts and other installed combinations.

Touch backer and lens use the frozen housing parameter scope. `captured.scad` has no `panel_z` assignment; `housing.scad` sets `H=43.6` and `panel_z=H`. The lens preserves the a11 assembly transform `translate([74.8,125.8,35.2+panel_z-34])`, producing world Z44.8. The module body/tail is receiving-only, generated and verified against `capture.json` context `touch_module_body_and_tail_reserve`: XY82,158 to135.848,179.844; Z17 to28. No actual electronics board or new geometry is invented. The source and the a11 placement provenance are hash-bound.
