# Private E19 input-ear layout feasibility proposal

This separate 77-part candidate extends the sealed six-stitch `e011588d` receiver without changing its original 76 parts, pin maps, traces, poses, quiet filter columns or authored In1 ground zone. The original receiver, PDN handoff, P03 and all canonical sources remain untouched. It is not adopted or released.

The added board ear occupies world [180,95]..[194,107] mm. Its new passive J13 force input has positive pad at world (188,100) and return at (188,104), corresponding to native (258,158)/(258,162). Both circular lands are 3.4 mm with nominal 2.2 mm finished bores at 4 mm pitch, using the same direct-solder AWG18 footprint as the parent. The bore/pretinned-wire, solder, strain, contact, edge tolerance and mechanical support processes remain unqualified. J13 is the proposed wired input; the old J1 wire remains unfitted service access in this private assembly.

The outline is the union of the old 150×65 mm board and the 14×12 mm ear. Nominal pad copper clearance to the lower edge is 1.3 mm, drill-edge clearance 1.9 mm and footprint-courtyard clearance 1.05 mm. The closest declared H4 head envelope is 7.25 mm left of the new pad courtyard. These planar figures do not prove housing, component, solder-tail or bent-wire clearance. Root-owned native ear/body/wire checks remain required.

Three new direct 5V fills occupy native [143,119]..[262,164] on F/In2/B, joining the old top power field and including the R1 input region. The quiet ADC filter columns at X113..137 are outside this rectangle. A separate In1 AGND extension occupies [248,153.5]..[263,164.5], overlapping the original plane without modifying it. The four new zones have priority1; original zones retain priority0. The initial native overlap-priority findings and exact repair are preserved under `generated/history/initial-priority0/` and `generated/zone-priority-repair.json`; no electrical clearance was relaxed.

Fresh complete ERC/DRC/warnings/schematic-parity/open counts are all zero. `generated/package-review.json` independently verifies every original component/pin map and the exact added pad package, BOM row and outline. `generated/native.json` and raw reports bind the actual source/refill; `generated/design-change.json` preserves the design-stage ledger rather than replacing the native proof. The saved source is `d55f9e48…`, with actual native refill `b9ece263…`.

The proposed input force/return electrodes are J13.1B/J13.2B. The shared input target is 2.4 A; existing Seed1A (including nested3V3) and LED5V0.764A branches account for 1.764 A. The remaining 0.636 A of other branches/reserve still needs real terminal and return assignments. It must not silently remain an ideal E28 star or be treated as zero. No complete 2.4 A branch/return proof is claimed.

No finite-PDN tensor has been run on this ear proposal. The old fixed 150×65 mm model domain cannot be reused: it would clip the new ear. After geometry approval, extraction must include the actual extended outline, new In1 return path, actual J13 source faces and all new filled geometry, with the S1 material/stackup requirements still unaccepted. Prior parent PDN results are not inherited. Ampacity, noise, dynamic/thermal, complete endpoint, solder/contact/strain, manufacturing and physical qualification remain false.
