# DAC reference geometry policy

This screen verifies the introduced copper and retains raw measurements for existing copper. It does not establish analog noise, stability, crosstalk, distortion, or fabrication acceptance. Existing authored zones, low-capacitance exclusions, component poses, and copper remain unchanged.

The low-capacitance mask follows `hardware/fabrication/audio_main_ground.py:58–72`: the original construction identifies OPA1612 inverting-input nets at U301–U304 pins 2 and 6, buffers their captured surface copper by 0.5 mm, and creates plane-only exclusions. The DAC audit uses the corresponding prefixed A_U301–A_U304 pins, reconstructs that **same 0.5 mm rule from baseline copper only**, then intersects it with the baseline's actual exclusions. It never buffers new tracks or expands an authored exclusion. Every accepted low-capacitance area is reported by net and original keepout UUID. Non-sensitive routes crossing those areas receive no exception. Overlap with original same-net pad/track copper is reported separately because it is not introduced copper.

New route coverage uses the connected adjacent LINK_AGND fields, with only the captured-zone fidelity allowance of 0.000002 mm. The former 0.0015 mm field dilation is not used for new-route acceptance. Each excluded new signal-via hole must match an independently verified transition by exact UUID, net, position, and native connectivity group; its identified ground conductor must also belong to the verified main ground group. All verified return corridors remain at most 2.5 mm long and have actual filled-copper contact on the relevant reference layers.

Existing-track reports retain the undilated raw loss. A separate numerical-boundary measurement uses the board's native `m_MaxError`, read from both before/after boards by pinned KiCad 10.0.7: 5000 internal units, or 0.005 mm. This is the native polygonization setting, not a selected threshold fitted to the residual. [KiCad's PCB documentation](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) describes its arc/circle approximation meaning. The [10.0.7 zone-filler source](https://gitlab.com/kicad/code/kicad/-/raw/10.0.7/pcbnew/zone_filler.cpp) takes that setting from the board and uses it when polygonizing clearances and pruning/re-expanding minimum-width features. Raw loss and the part lying within this boundary band remain visible separately; any loss beyond the band requires an explicit physical explanation.

A newly introduced same-net via can remove adjacent reference directly beneath a retained track that it physically contacts. This is counted only when native via copper intersects that exact old track, the net and connectivity group match, and the same via UUID has a verified return corridor. The local bound is derived from the unchanged In1 zone settings: via radius + 0.2 mm clearance + half the 0.25 mm minimum fill width + native polygonization error. The upstream filler performs shrink/grow minimum-width pruning, so this covers its local knockout smoothing beyond the nominal clearance circle. The report records the track/via copper contact area, actual attributed loss, envelope radius, return UUID, and verified return length. It does not waive losses near unrelated vias or tracks.

The 0.1 mm added-drill-to-SMD-copper minimum comes unchanged from `hardware/fabrication/smd_drill_review.py` and is checked independently using native captured SMD polygons and actual new via drill diameters. Mask, stencil registration, and manufacturing process acceptance remain open.
