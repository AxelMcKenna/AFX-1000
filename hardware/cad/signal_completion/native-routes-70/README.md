# Right-channel ADC negative bias

A_R132 pin 2 joins the existing A_R137 pin 2 bias group. The 52.03 mm route uses 0.20 mm traces, four 0.60/0.30 mm vias and adjacent ground on each routing layer. The ground-reference check allows up to 5 nm at a polygon boundary and records the measured area for each leg. Native connectivity leaves 56 open connections. The ES9292QPRO footprint is pending.
