# Gain relay coil return

A_Q602 pin 3 connects to the A_K401 pin 8 coil-return group through 47.29 mm of 0.20 mm copper. The route adds one 0.60/0.30 mm via and lands at the center of the existing return via. The front and In3.Cu segments reference ground on In1.Cu and In4.Cu, respectively. The pad-group comparison verifies 58 remaining open connections. The ES9292QPRO footprint is pending.
