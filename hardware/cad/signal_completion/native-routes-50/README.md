# Right ADC reference buffer input

A_U104 pin 10 connects to the rear divider trace through a single 0.60 mm via with a 0.30 mm drill. The adjacent buffered-reference branch clears the pickup. The positive analog supply keeps its 0.60 mm trace width through a local detour on In2.Cu. Refilled ground copper supports the changed traces and the via transition. KiCad verifies 78 open connections.
