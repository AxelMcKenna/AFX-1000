# Codec enable buffer connection

A_U210 pin 6 drives the existing A_U207, A_R209 and A_TP402 pad group through 1.28 mm of 0.20 mm copper and one 0.60/0.30 mm through via. The In2.Cu 3.3 V trace retains its 0.60 mm width. The buffer and its local bypass remain in place. Both signal traces reference ground copper connected to the nearby ground via. KiCad verifies 63 remaining connections. The ES9292QPRO footprint is still pending.
