# Codec supervisor divider

A_R211 pin 2 connects to the existing junction of A_R212 pin 1 and A_U206 pin 1. The 0.20 mm route on In5.Cu and B.Cu uses one new 0.60/0.30 mm via. KiCad reports 53 remaining open connections and the missing codec footprint.
