# Left ADC reference buffer input

A_U104 pin 3 connects to the divider on In3.Cu through a 0.60 mm via with a 0.30 mm drill. Local detours preserve the widths of both analog supply traces. Refilled ground copper supports the pickup on In1.Cu and In4.Cu. KiCad verifies 77 open connections.
