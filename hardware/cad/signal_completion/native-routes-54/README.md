# Left ADC charge-pump filter feed

The charge-pump reservoir A_C110 connects to filter resistor A_R116 through 21.79 mm of copper and two 0.60 mm vias with 0.30 mm drills. Each section runs over a continuous ground reference that connects to a nearby ground via at the layer transition. KiCad verifies 73 remaining open connections. Ripple and coupling into the ADC input remain to be measured.
