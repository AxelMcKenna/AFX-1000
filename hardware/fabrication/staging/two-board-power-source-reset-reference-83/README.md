# Source reset bias network

A 23.22 mm front-layer trace joins P_R402 pin 1 to P_R401 pin 2 on AX03_SOURCE_RESET. Two existing system-ground vias connect the In1.Cu ground beneath the full trace width. One intended pad-group join reduces the remaining open connections to 1,397.
