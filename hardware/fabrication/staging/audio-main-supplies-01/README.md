# Unselected initial supply-routing construction

This draft was rejected before native acceptance. Its planner retained raster
node targets after simplifying copper into chords, so a later branch target
could lie away from emitted copper. The successor filters targets against the
actual emitted centreline and retains grid turns. None of this draft is selected,
qualified or released. Original input, construction and executed source are
preserved for diagnosis; no manufacturing outputs or order were produced.
