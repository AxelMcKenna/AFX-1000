# Fan load-switch input bypass

The 100 nF input bypass capacitor F_C201 connects to fan load switch F_U201 through 0.50 mm front copper. Ground beneath each trace returns through an existing system-ground via. The previous branch from the capacitor to the enable pin was removed. The enable pin remains tied to VIN. KiCad confirms all original pad groups and 1,224 remaining opens.
