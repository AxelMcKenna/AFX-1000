# Ground returns for rail monitoring

Six divider resistors and comparator M_U4 connect to the main analog ground plane on In4.Cu through seven local 0.30 mm tracks and seven 0.60 mm vias. Track lengths range from 1.12 to 2.41 mm. The native refill verifies the via lands contact the ground plane and the named ground pads join the main ground network.

KiCad confirms seven intended pad-group joins and 1,451 remaining open connections. Geometry and schematic parity pass. ERC retains the two isolated-reference warnings. Both PCB placements match the assembly capture.
