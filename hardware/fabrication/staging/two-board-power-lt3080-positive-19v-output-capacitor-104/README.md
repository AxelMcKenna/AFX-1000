# Positive 19 V regulator output capacitor

Two parallel 0.60 mm paths join P_U7's output pad to its existing 22 µF rear capacitor P_C37. Each path uses one through via. The capacitor's ground connection reaches the adjacent ground planes. KiCad verifies one intended join and 1,313 remaining connections. Regulator stability and capacitance at operating bias still require loaded measurements.
