# Analog support placement candidate 01

Jointly packs the twelve support passives for U13/U14/U32 while retaining the
ICs and input capacitors. The bounded search checks courtyards, body/tail
reserves, pad-to-copper and drill clearances, then a complete mechanical screen.
Three passives change face. Native pose confirmation, local routing, quiet-return
ownership, fills and independent/native validation are still required.

The selected board remains TBP44. This candidate is not a fabrication release.
The [circuit review](../two-board-analog-support-review-01/README.md) records the
three quiet-return networks and exact existing branches that must be restored.
The archived search scripts retain their scratch-path references; placement.json
is the explicit native pose input, with all declared moves and retired objects.
