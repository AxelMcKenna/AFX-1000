# Local rail-threshold and timeout connections

Seven surface traces connect six local sense, reference and trim paths and one timing-capacitor pair. Each trace runs directly between pads on the same side, with lengths from 3.19 to 5.70 mm and a width of 0.20 mm. Native KiCad connectivity confirms exactly seven pad-group joins, taking the power board from 1,886 to 1,879 opens.

Each new trace has adjacent connected ground underneath the exposed span. All 5,736 original board objects and all 47 saved zone fills are preserved. The footprint locations and board geometry match the enclosure capture. Threshold accuracy, noise and timeout behavior still require electrical qualification.
