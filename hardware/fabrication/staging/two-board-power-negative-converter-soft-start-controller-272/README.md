# Negative converter soft-start controller connection

P_U13 pin 7 joins P_C76 and P_R50 on the negative converter soft-start node. The two 0.25 mm traces total 9.62 mm. A ground via 0.90 mm from the signal via connects their two reference layers.

KiCad verified the expected pad groups. The board has 904 remaining open connections.
