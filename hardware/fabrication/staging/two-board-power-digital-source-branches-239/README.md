# Digital 5 V source branches

The new branches connect 3 previously separate groups assigned to PWR_5V_DIG_SRC. Every branch runs over existing ground copper. The native connectivity check covers every pad on the board and leaves 967 opens. The plane review records which pads now reach the 5 V regulator and which loads still have an open path.
