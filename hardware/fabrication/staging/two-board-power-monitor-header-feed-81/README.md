# Rail monitor header supply

Two 0.40 mm front-layer branches connect the 3.3 V supply on M_J1 pin 2 to M_R112 and M_R43. The adjacent In1.Cu ground copper contacts M_J1 pin 3 and provides a continuous reference under both traces. KiCad verifies two intended pad-group joins and 1,401 remaining open connections.
