# Negative shunt reference cathode

P_U12 pin 6, the cathode of the LT1634 negative reference, connects to the ground plane through a 0.91 mm rear-layer trace and one 0.60/0.30 mm via. The new via clears the module-feed plane on In2.Cu. KiCad verifies 1 pad-group joins and 1,145 remaining connections.
