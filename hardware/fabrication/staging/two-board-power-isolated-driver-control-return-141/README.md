# Isolated driver control-side ground

A 3.43 mm front trace connects the control-side ground pin of E_U1 to an existing system-ground via. The trace stays on the control side and its copper edge clears the projected floating output copper by 4.01 mm. The input and output package pad banks are 3.00 mm apart. KiCad verifies 1 pad-group joins and 1,212 remaining connections.
