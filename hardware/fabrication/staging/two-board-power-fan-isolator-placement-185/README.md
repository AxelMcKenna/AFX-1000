# Fan optical switch placement

F_U15 moved from (46.5, 165) to (41, 169) mm. A 9.97 mm front-layer branch connects its LED anode to the existing circuit. In1 provides continuous ground beneath this branch. The copper keepout covers the input-output gap on all eight copper layers. The relocation preserves all existing pad groups and all previously filled copper areas.

The whole-board isolation survey records 51 layer intersections, down from 62. The power board has 1,078 connections still to route. Voltage withstand and fabrication qualification remain open.
