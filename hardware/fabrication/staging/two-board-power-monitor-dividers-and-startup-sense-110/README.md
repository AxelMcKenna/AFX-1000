# Rail monitor and negative startup sensing

Short 0.20 mm surface traces connect the local rail-monitor dividers and negative startup sensing circuitry. Each trace has continuous adjacent ground copper connected to an existing ground via. KiCad verifies 8 intended pad-group joins and 1,298 remaining connections. System startup and monitor accuracy still require loaded measurements.
