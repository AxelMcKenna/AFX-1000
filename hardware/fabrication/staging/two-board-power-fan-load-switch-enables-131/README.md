# Fan load-switch enable connections

The enable inputs of F_U201, F_U301 and F_U401 connect to their local input pads through 0.25 mm copper. Ground beneath each trace returns through an existing system-ground via. KiCad verifies 3 connections and 1,226 remaining opens. These traces carry enable-input current.
