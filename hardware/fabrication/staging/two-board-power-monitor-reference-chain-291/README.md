# Positive 12 V overvoltage reference resistor chain

M_R33 and M_R34 sit together on the bottom side near the M_R35 and M_R36 reference divider. The 1.91 mm connection between M_R33 and M_R34 moves with the pair. The relocated pair uses no new vias. A 3.71 mm bottom trace joins M_R34 to the divider base, with continuous In6 ground beneath both traces. M_R33 pin 1 still requires its 2.5 V reference connection.

KiCad verified all named pad groups and 880 remaining open connections. [Resistor placements](component-placement.json)
