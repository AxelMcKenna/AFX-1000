# Local 1 V regulator reference bypass

The rear 100 nF bypass P_C72 sits beside P_U13. A 0.64 mm front trace and 0.98 mm rear trace connect REF pin 3 to P_C72 through a 0.60/0.30 mm via. The 0.90 mm return connects directly to an exposed-pad ground via. Native connectivity verifies two new pad-group joins and 1,197 remaining connections.
