# Regulator set points, feedback and negative bias control

The positive and negative 19 V set-point networks gain local connections, along with the positive 19 V feedback divider and a negative bias logic connection. Each trace runs over continuous ground on its adjacent layer. KiCad verifies four intended joins and 1,316 remaining open connections. Regulator stability and accuracy still require loaded measurements.
