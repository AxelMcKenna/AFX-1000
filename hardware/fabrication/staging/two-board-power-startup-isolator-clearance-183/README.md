# Startup isolator copper separation

The 1.78 mm keepout between the input and output lands of N_U24 excludes tracks, pads, vias and pours on all eight copper layers. The front-layer N12_START_CONDITIONED detour adds 6.41 mm and preserves ground directly beneath its full length on In1. The native pad-group comparison preserves all 1,078 remaining opens.

The whole-board isolation survey found 65 layer intersections, down from 69. The loaded layout and regenerated copper have the same filled geometry. Input-to-output voltage withstand and fabrication qualification remain open.
