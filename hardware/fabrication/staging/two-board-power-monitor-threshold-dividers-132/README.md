# Rail-monitor threshold dividers

M_R47 connects to M_R48 on the negative 12 V overvoltage threshold divider. M_R33 connects to M_R34 on the positive 12 V overvoltage threshold divider. Both routes use 0.25 mm copper. Ground beneath each trace returns through an existing system-ground via. KiCad verifies 2 connections and 1,224 remaining opens.
