# Negative output feedback

Each 0.20 mm route uses one 0.60 mm through via with a 0.30 mm drill. These connections serve the negative startup amplifier. Ground-plane copper backs each trace to its destination via. KiCad verifies 1 intended joins and 1,283 remaining connections.
