# Low-voltage positive rail soft start

The rear soft-start capacitor P_C74 sits beside P_U13. A 0.64 mm front trace and 0.46 mm rear trace connect positive soft-start pin 9 to P_C74 through a 0.60/0.30 mm via. The 0.46 mm return connects directly to an exposed-pad ground via. Native connectivity verifies two new pad-group joins and 1,195 remaining connections.
