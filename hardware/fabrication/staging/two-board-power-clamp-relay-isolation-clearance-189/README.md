# Clamp relay copper separation

The 2.50 mm keepout between the input and output lands of N_U12 excludes tracks, pads, vias and pours on all eight copper layers. The keepout spans the full modeled relay body and both ends of the contact-bank midline. Existing tracks and component positions are unchanged. The native pad-group comparison preserves all 1,074 remaining opens.

The whole-board isolation survey found 46 layer intersections, down from 48. The loaded layout and regenerated copper have the same filled geometry. Input-to-output voltage withstand and fabrication qualification remain open.
