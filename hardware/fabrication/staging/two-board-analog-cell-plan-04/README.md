1.000–1.281 mm escapes to owned quiet vias. A dedicated U32 stitch joins the
capacitor reference field to the quiet In1 region. The native component poses
and zone-independent geometry screen pass.

U31/U14 enable backbone that had been retired with R100's former remote branch.
[Plan 05](../two-board-analog-cell-plan-05/README.md) corrects those issues.
